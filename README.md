# vclvlc
名称
FmxVLC メディアプレーヤー

作者HP
https://sites.google.com/site/delphiuserhotkey/
http://terukohietori.nrt.buttobi.net/



VLC Media Playerの機能を使ったメディアプレイヤーです

Windows Media Player を使いやすく

有償のプレイヤーよりは軽くを目安にカスタマイズしてみました。

VLC Media Playerの他にPosLibVLCを使わせていただいています。


インストール・アンインストール
圧縮ファイルを解凍してお好みのフォルダに設置してください。
アンインストールは圧縮ファイルを解凍したものを削除してください。

libvlc.dll, libvlccore.dll, plugins folderは動作に必要です。
アプリと同じフォルダに置いてください。
